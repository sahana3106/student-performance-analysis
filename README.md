# Student Performance Analysis

## Project Overview
This project focuses on analyzing and visualizing student performance data using Python and data visualization techniques.

The analysis explores how different factors such as parent education, study-related attributes, and student characteristics influence overall student scores.

---

## Dataset
The dataset contains information related to:
- Student scores
- Parent education
- Study-related attributes
- Other student performance factors

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Analysis Performed

### Data Visualization
Created visualizations to analyze:
- Parent education vs overall score
- Score distribution
- Student performance trends
- Comparison between different student-related factors

### Insights
- Some factors showed only slight variation in student scores
- Student performance appears to depend on multiple combined factors
- Visualization helped identify trends and patterns within the dataset
